# 3000—5000词汇进阶｜40节PPT

米白、深蓝、橙色封面；每课一个完整PPT，含上、下两部分。封面后的学习流程图均已加入，课次、上/下、词数和封面代表词可以直接选中修改。

统一顺序：**上封面 → 流程图 → 第1—25词 → 下封面 → 流程图 → 第26词至本课结尾**。

- 第1页：上封面；第2页：流程图。
- 第28页：下封面；第29页：流程图；第30页开始第26词。
- 第1—20课迁移原有单词页，文字、图片和可编辑形状不变。
- 第21—40课按已提供的小程序词序补齐，采用可编辑的释义、音标、用法/词形、双语例句页面；有对应word-atlas条目时补充其搭配与辨析，无对应条目时使用小程序本地资料，不虚构搭配。此部分没有原课件照片，不把前20课照片错配给新词；个别过长例句已改写为准确短句。
- 第17课保留grip补充词；第20课保留decision-making、full-time、high-profile补充词。
- 第40课实际46词，下集为第26—46词，没有补入无关单词凑数。

全套覆盖小程序的1996个不同词，共2000个词条页面（含4个原课件补充词）。全套共2160页；第17课55页、第20课57页、第40课50页，其余54页。
